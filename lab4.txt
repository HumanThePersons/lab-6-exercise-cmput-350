#### Question 1
Everytime the mandlebrot function is called it has to go through each pixel, and as maxIters increases, so does the time it takes for each pixels to run. This means that using the smaller maxIters saves some time and thus responsiveness, to make zooming / panning cleaner. Then when the user is looking at a still image, we can use the 3200 maxIters for a more accurate view of the set
